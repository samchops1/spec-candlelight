## Color (v3 — warm dark editorial, NOT cool glass night)

| Token | Hex | Use |
| --- | --- | --- |
| `--bg` | `#100c09` | Warm near-black (brown-black) page ground |
| `--bg-elev` | `#1a1410` | Solid lift behind chapters / film band |
| `--card` | `#221c16` | Quiet solid panels (NO glass, NO blur) |
| `--ink` | `#f2ebe0` | Warm paper type |
| `--muted` | `#a89a88` | Meta, chips, hours |
| `--line` | `rgba(242,235,224,0.10)` | Hairline only |
| `--amber` | `#c4893a` | Accent only — kickers / primary CTA |
| `--amber-soft` | `rgba(196,137,58,0.14)` | Soft chip wash |
| `--bronze` | `#d4b896` | Pull quotes |
| `--red` | `#b54a3c` | Thin listen rail |
| Film player | `#0a0806` | Media well |

**Do:** warm `#100c09`, solid quiet cards, Cormorant display, Source Sans body, photo bleed.  
**Don’t:** cool `#07080c`, `backdrop-filter`, frosted glass, Syne/Inter neon-product look, plastic `#ff8a1a` on black.

| Kickers | Source Sans, amber uppercase |

## Components

- Mast: solid warm sticky `#100c09` / `#1a1410` — **no blur**
- Cards / chips / timeline / visit: solid `--card`, hairline, quiet
- CTA primary: solid amber, dark label
- CTA ghost: outline ink/line — no glass fill
- Film: elevated solid band; dark player; solid play disc
- Frames: photo bleed + soft shadow; no frosted border

## Motion
Fade-in only. Film click-to-play.

## Don’t invent
No painting, shooting, shuffleboard, quote grids.
